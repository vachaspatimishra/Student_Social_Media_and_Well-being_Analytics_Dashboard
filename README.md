# 📊 Student Social Media & Well-being Analytics Dashboard

An interactive **Power BI dashboard** that analyzes how social media usage impacts students mental health, academic performance, sleep patterns and relationships. The dashboard enables users to explore trends through interactive filters, drill-through pages and visualizations.

---

## 🚀 Project Overview

This project transforms raw student survey data into actionable insights using Power BI. It demonstrates data modeling, DAX calculations, interactive reporting, and data storytelling to help educational institutions understand the effects of social media on student well-being.

- 📈 **705** Students Analyzed

## 📄 Dashboard Pages

- **Executive Overview** - KPIs and overall trends
- **Mental Health & Lifestyle** - Addiction, sleep, and mental health analysis
- **Academic Impact** - Social media usage vs academic performance
- **Relationships & Conflicts** - Relationship status and conflict analysis
- **Interactive Story View** - Dynamic dashboard with slicers
- **Student Profile** - Drill-through page for individual student analysis

---

## 📊 Key Business Insights

- **64.3%** of students reported that social media negatively affects their academic performance.
- Students spend an average of **4.92 hours/day** on social media.
- **Instagram (249)**, **TikTok (154)**, and **Facebook (123)** contribute the highest academic impact among all platforms.
- Undergraduate students show the highest cumulative social media usage (**1,766 hours**).
- Students with higher addiction scores generally have lower mental health ratings, indicating a negative relationship between excessive usage and well-being.
- Average sleep duration is **6.87 hours/day**, slightly below the recommended 7–9 hours.
